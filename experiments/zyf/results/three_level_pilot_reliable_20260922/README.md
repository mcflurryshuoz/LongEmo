## 修复与协议

- 音频提示明确区分人物声音、音乐、环境声和静音，继续严格校验来源、时间和事实描述。
- noevent 可直接复用给定 cast 中的人物 ID；新人物使用局部 ID，不猜程序分配的 ID。
- 事件、状态与关系必须引用本窗口真实观察；无证据时省略，保留原校验。
- 修复跨窗事件从空置信度更新为有效置信度时的报错。
- 感知、规划和回答最多三次有限格式修复；明确暂时网络故障可在同一预算内重试。内容拒绝、认证／额度及未知失败停止；失败原输出保存在权限为 0600 的本地诊断文件，仓库不提交这些文件或密钥。
- 官方评分固定一次，保留首次有效结果，包括 0 分。每个视频只启动一次新断点任务，不自动增加外层重启。
