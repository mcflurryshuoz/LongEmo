# BlackAI 模型可用性实测

2026-09-21，在 g450 使用现有 BlackAI 凭据测试。**Gemini 3.6 Flash 与 Gemini 3.1 Pro Preview 均在真实音频和视觉图谱请求中一次通过。** 本次为 V71/W50 单窗口验证，不是整集图谱或新评测得分。

| 请求模型 ID | 简短文本 | 真实音频 | 视觉及图谱结构 | 实测音频＋视觉耗时 |
|---|---|---|---|---:|
| `gemini-3.6-flash` | 通过 | 一次通过 | 一次通过；3 个观察、3 个事件 | 约 50 秒 |
| `gemini-3.1-pro-preview` | 通过 | 一次通过 | 一次通过；6 个观察、2 个事件 | 约 138 秒 |
| `gemini-3.1-flash-lite` | 通过 | 一次通过 | 首次关系缺少证据 ID；后续独立校验通过 | 单次视觉约数秒；存在额外诊断调用 |
| `gemini-2.5-flash` | HTTP 404 | 未继续 | 当前账号组无支持该模型的上游 | — |

范围：980–1000 秒核心窗口，两边各 2 秒 padding，8 帧、max_pixels=150528；原图谱 JSON 校验规则不变。音频观察不包含题目、参考答案或评分标准。

建议下一轮小批补评先采用 `gemini-3.6-flash`，`gemini-3.1-pro-preview` 作为备用；单窗口通过不保证其他场景均能完成，也不证明准确率提升。本次没有改动已有图谱、答案或首次有效评分，新增评分为 0。

返回模型版本：3.6 视觉响应为 `gemini-3.6-flash-tiered`；Pro Preview 为 `gemini-pro-default`。应同时记录请求 ID 和返回版本，不能据代理别名确定真实上游模型。

Flash Lite 补充诊断 v1 将已提供的音频观察错误标记为 `sampling.audio=False`；该检查及其反馈修正被排除。v2 修复诊断元数据后首个视觉请求通过，未更改方法校验器。所有尝试和结果保留在独立 diagnostics 目录，避免隐藏失败。

详细请求哈希、HTTP 状态、结构校验与耗时见 [validation.json](validation.json)。此前“BlackAI 尚无可替代路由”的判断已被本次新测试更新；不能从 3.5/3.7/3.8 的失败推断其他模型不可用。
